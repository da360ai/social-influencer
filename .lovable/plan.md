# Editorial workshop landing page redesign

## Goal
Rebuild the complete workshop page using the supplied fashion-site reference as the visual direction, while keeping every workshop section and booking interaction intact.

## Build
- Create a white editorial canvas inside a bold black frame.
- Recompose the opening around oversized type, an asymmetric image mosaic, compact labels, and strong color blocks.
- Carry the visual system through curriculum, outcomes, bonuses, mentor, audience fit, takeaways, venue, FAQ, and final booking.
- Preserve form validation, simulated payment confirmation, calendar download, map, countdown, and mobile booking bar.
- Verify the result at desktop and mobile sizes and test the booking flow.

## Visual system
- Palette: ink black, paper white, coral, marigold, mint, and sky blue.
- Typography: Outfit display with Figtree body copy.
- Shape language: crisp borders, restrained 8px corners, circular micro-labels, and offset grids.
- Motion: subtle lifts and existing smooth scrolling, with reduced-motion support.
